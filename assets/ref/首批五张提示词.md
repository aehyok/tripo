# 首批五张图片 · 最终提示词

生成方式：内置 image_gen 工具。
街景为风格参考；吉拿母图仅沿用街景的造型语言，其余三个角色视角均以吉拿母图为输入。

## 街区夜景全景

```text
Use case: stylized-concept. Generate one landscape image, 1536x1024.
用途：游戏关卡的概念氛围参考图，用来统一后面所有资产的配色、饱和度和造型语言，不用于建模。
主体：一条比赛散场后的墨西哥球迷街。街道一侧并排三栋两层小楼，墙面分别是洋红 #E5127D、青绿 #1CC0C9、金盏黄 #FFB31A；街边有一个木质球迷摊位（奶油白与金盏黄条纹遮阳篷）和一辆洋红色小吃推车，三角纸旗和暖色串灯横跨街道、挂在屋檐之间，石板路上滚着一个足球。
构图：横幅画面，街道纵深透视，镜头略高于人眼、轻微俯视，三栋房屋完整可见，远处街道尽头留出空间；画面里不要出现人物或动物。
风格：风格化 3D 游戏场景，简化几何体，边角圆润倒角，贴图带手绘明暗，深蓝紫夜色（约 #161B4D）与高饱和暖色灯光形成对比，整体像精致的休闲独立游戏，不要写实照片，不要赛博朋克霓虹，不要卡通描边。
光线：主光源为深蓝紫色的环境天光，暖色光只来自灯笼、串灯和摊位灯泡的发光材质，不照亮整条街；整体偏暗，但房屋、摊位、小吃车的轮廓都清楚可辨。
材质：灰泥墙面、木料、帆布、纸、陶土，全部哑光。
限制：不要文字，不要招牌，不要品牌标志，不要真实球队队徽，不要人物，不要汽车。
```

## 吉拿 3/4 前视母图

```text
Use case: stylized-concept. Generate exactly ONE square 1024x1024 image, one dog only, NOT a contact sheet.
输入图只作风格参考：只沿用它的造型语言（简化几何、圆润倒角、手绘贴图感）和色彩饱和度，不要沿用它的夜间光照、深色背景、构图或其中的任何物体。本图按下面写的棚拍光和纯色背景出图。
用途：作为图生 3D 的设计母图，后续的正视、左侧视、后视都以这张为输入改视角；主体需要能被单独建模，不要场景化。
主体：一只风格化卡通小狗，棕黄色短毛（主色 #D99A5B，耳尖和尾尖略深 #B97B3F，口鼻和肚皮略浅），圆脑袋、立耳、短吻、卷尾，体型紧凑结实，头部偏大（约占身长的 1/3）；穿一件绿色短袖足球球衣（主色 #12A66A），胸前一道奶油白 #FFF4DC 横条，无品牌、无队徽、无号码、无文字；球衣贴身，下摆不盖住后腿；四条腿垂直站立，前腿与后腿前后错开，左右腿之间留有明显空隙，四肢与躯干之间轮廓分明；头部抬起平视前方，表情友善活泼；不叼球、不背包、不戴项圈、没有任何道具。
构图：画面中只有这只小狗，镜头位于小狗左前方约 30°（头部朝画面左前方，同时看到正脸和身体左侧），镜头高度与小狗胸口齐平，长焦视角，透视压缩小；主体居中，纵向占画面约 70%，四周留白，四只脚和整条尾巴完整入镜。
风格：风格化 3D 游戏角色，简化几何体，边角圆润，轮廓干净，大色块分明，哑光质感，贴图带少量手绘明暗，与休闲独立游戏的角色造型语言一致，不要写实照片感。
光线：均匀中性棚拍光，正面偏上主光 + 两侧柔和补光，无硬投影，无高光溢出。
材质：短绒毛哑光表面（毛发用贴图表现，不做蓬松的立体毛簇），球衣为哑光棉质布料，褶皱少而简洁。
背景：纯浅灰 #ECECEC 无缝实底，无地平线，无投影，无地台。
限制：不要文字，不要水印，不要品牌标志，不要多个物体，不要广角畸变，不要景深虚化，不要球，不要项圈，不要牵绳。
```

## 吉拿正视（修正四肢数量后的最终版）

```text
Use case: identity-preserve. One square PNG image, one single full body dog, no contact sheet. 输入图是唯一角色母图，保持同一只吉拿，只改观察视角。
沿用输入图中这只小狗的造型、体型比例、毛色、球衣款式与配色、材质质感，只把观察视角改为：镜头正对小狗正面，头部正对镜头，身体左右对称，四条腿都能看到。严格正视图，不是3/4视图。
不要重新设计角色，不要改变任何造型细节、颜色或比例。保持大立耳、短吻、奶油色眉斑与口鼻、棕黄短毛、卷尾、绿短袖球衣，以及母图已有的衣服细节。四肢自然垂直站立，不改变姿势，只移动镜头。
主体在画面中的大小与输入图一致：头顶和脚底的高度位置不变，居中，四周留白，四只脚和整条尾巴完整入镜。镜头高度与小狗胸口齐平，长焦视角，几乎没有透视。
保持同样的风格、均匀中性棚拍光和纯浅灰 #ECECEC 无缝实底背景。颜色只来自角色自身，不加入环境染色。
不要文字，不要水印，不要多个物体，不要投影，不要地台，不要项圈或任何道具。
关键解剖约束：整只狗严格只有四条腿、四只脚：两条前腿、两条后腿。正视镜头下，前腿分别位于画面左、右两侧；后腿在两条前腿之间各露一只脚，共计只能看见4只脚。禁止第五条腿，禁止额外脚掌，禁止肚子中央长出一条腿。身体和脸正对镜头，保持母图同一角色。优先保证四肢数量正确。
```
