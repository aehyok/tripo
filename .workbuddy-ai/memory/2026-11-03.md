- 产出：H:/github/tripo/资产生产手册.md，把 PRD §8 资产清单拆成可执行产线：gpt-image 2.5 → Tripo → Blender → GLB → Cesium。
- 出图清单 21 张：风格锚定 2、吉拿 4 视图、小年 4 视图、场景道具 6、贴图 2、2D 头像与卡片 3。
- Tripo 分流 8 次：小年/吉拿走多视图，house/stall/cart/pinata/cactus/lamp 走单图；足球、木箱、纸旗、地面、UI 明确不进 Tripo（Blender/Cesium 直做更省）。
- 关键技术结论（已核对官方文档）：
  1. Cesium `Model.fromGltfAsync` 的 `forwardAxis` 默认 `Axis.Z`、`upAxis` 默认 `Axis.Y`；因此 Blender 里模型正面朝 **-Y** 即可零参数对齐（Blender -Y → glTF +Z）。
  2. `clampAnimations` 默认 true，切动画会卡上一帧，必须设 false，且切前 `activeAnimations.removeAll()`。
  3. 动画名靠 `gltfCallback` / `model.gltfInternal.json.animations` 建 name→index 映射，不猜 index。
- Blender SOP 要点：1 单位=1 米、按尺寸表校正并 Apply Scale、原点归到脚底中心（Location 0,0,0）、面数预算（小年 8–15k、道具 1–4k）、房屋三配色用 `贴图 × baseColorFactor`（Mix Multiply）保留木纹、碰撞代理单独 COLLIDERS 集合收缩 5–10%、导出 +Y Up / NLA Tracks / 暂不开 Draco。
- 顺序约束：吉拿跑通全链路（PRD M2）之前不碰第二个资产。


## 按 PRD 实现第一关（Cesium 迁移 + P0/P1 修复）

- 产出：根目录改为 Vite + CesiumJS 项目（`package.json` / `vite.config.js` / `index.html` / `src/`），
  旧原型移到 `legacy/环球寻物.html`（Vite 会把根目录所有 html 当入口，必须移走）。
- 目录：`src/main.js` 状态机、`src/config.js` 全部可调数值、`scenes/{earth,street,streetProps}.js`、
  `core/{audio,progress,tween,ui}.js`、`data/world.json`（从原型抽出的陆地/墨西哥轮廓，518KB）。
- 关键实现：
  1. 地球底图 = 运行时 Canvas 自绘 + `SingleTileImageryProvider.fromUrl(dataURL)`，零在线地图依赖。
  2. 墨西哥高亮用无 height 的 ground polygon（ClassificationType.TERRAIN）+ clampToGround polyline；
     小点用 billboard 脉冲。`scene.sun.show=false` 去掉太阳光斑。
  3. 街区锚点 -99.1332/19.4326/2240，`Transforms.eastNorthUpToFixedFrame` 局部 ENU；
     占位模型用 box/cylinder/ellipsoid/polyline 实体拼装（约 250 个实体）。
  4. 相机 `camera.setView({destination, orientation, endTransform: IDENTITY})` 每帧写；
     遮挡用自写 ray-AABB（不用 Cesium 拾取）；贴墙时抬 pitch、靠近吉拿时绕 yaw 0.42 弧度。
  5. 进出街区时 `scene.globe.show=false/true`，否则 2240m 高度会看到远处地表。
- 踩坑记录：
  - `#iris` 的 `clip-path: circle()` 语义：0% = 完全露出，150% = 完全遮住（原型里 open→0），一开始写反导致全屏黑。
  - Cesium 实体 `ellipse.height` 是**绝对海拔**，不是相对 position；必须用 ANCHOR.height 偏移。
  - `BillboardGraphics.show` 与 `Entity.show` 是 AND 关系：构造时 `billboard.show:false` 后只改 entity.show 不生效。
  - 原型里 `rayBox` 起点在盒内会返回 null（视为未命中），用于视线/相机判定时需保证起点合法。
  - Cesium 只给一盏主光源：夜景靠 `DirectionalLight` 强度 + 贴地柔光贴图（radial gradient ellipse）表现。
- 验收（Playwright + swiftshader，1.8fps 但逻辑可测）：三藏点 BFS 可达、视线隔墙不可确认、星级 3/2/1 组合、
  下蹲相机降 0.70m、提示方向"你右边"、找到后立即返回不弹旧结算、进场途中返回相机复位、15s 慢加载遮罩自动消失、存档重载显示 ★★★。
