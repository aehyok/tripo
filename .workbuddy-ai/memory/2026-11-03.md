  5. 进出街区时 `scene.globe.show=false/true`，否则 2240m 高度会看到远处地表。
- 踩坑记录：
  - `#iris` 的 `clip-path: circle()` 语义：0% = 完全露出，150% = 完全遮住（原型里 open→0），一开始写反导致全屏黑。

  - Cesium 只给一盏主光源：夜景靠 `DirectionalLight` 强度 + 贴地柔光贴图（radial gradient ellipse）表现。

## 地球底图重做（用户反馈“不像 Cesium、放大没变化”）

- 问题定位（不是“没换 Cesium”，是三个具体缺陷）：
  1. 底图是**单张 4096 贴图**（`SingleTileImageryProvider`），放大只是拉伸，无新细节；
  2. `globe.enableLighting=false` → 球面没有明暗过渡，看着像贴在屏幕上的圆盘；
  3. `minimumZoomDistance = 1.4e6`，1400km 就到底了，所以“放大没有任何变化”。
- 方案：新增 `src/scenes/globeTiles.js`，自写 `ImageryProvider`：
  - 按 `GeographicTilingScheme`（0 级 2×1 块，每块 180°×180°）逐级把 `world.json` 重绘成 256×256 瓦片；
  - `Path2D` 按度坐标预建 + 10° 网格空间索引剔除无关环；跨经线用 ±360 偏移副本；
  - 经纬网间隔随层级加密（30/10/5/1°），`maximumLevel=8`；
  - 云层用**世界坐标 fBm**逐瓦片生成（96×96 上采样），无缝、细节随层级下潜。
- 光照：`globe.enableLighting=true` + 固定 `DirectionalLight`（日下点 -55,12，让墨西哥受光偏侧）。
  **踩坑**：`street.build()` 会把 `scene.light` 换成街区局部光，回地球必须 `applyLight()` 复位——
  已挂到 `setControlsEnabled(true)` 里。
- 高亮渐隐：`applyFill()` 按相机高度算 alpha（>2.2e6 全亮 0.86，<1.05e6 归零），
  否则推进到 1100km 整屏都是一块纯橙色。
- 云层**踩坑**：fBm 粗八度主导均值 → 固定阈值 0.5 让整片区域全透明（墨西哥 level 5 均值仅 0.34）。
  改成“粗层定气候 + 细节层定形状”，粗层固定在世界坐标且任何层级都参与，`0.5+(coarse-.5)*0.7+(detail-.5)*0.95`，
  实测各级 sd 0.08~0.21、覆盖率 0.22~0.68，不再有死区。
- 性能：陆地瓦片 0.5~0.7ms/张，云瓦片 2.5~3.6ms/张（首次），可接受。
- 验收：缩放 18.5M→4e5 全程有变化；2600km 橙色区域清晰、1100km 高亮让位给地表；
  选关页云量单独降到 0.3；生产构建 `issues: []`；街区光照未受影响（截图确认）。
