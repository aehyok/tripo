# 图片 → Tripo → 原始 GLB

交付可追溯的原始 GLB、真实模型预览和处理记录。区分参考图、Tripo 原始模型、Blender 成品、游戏接入四个阶段；下载成功只代表第二阶段。

## 确定当前进度

1. 读取工作目录的 `AGENTS.md`、资产清单/生产手册及进度文档，保留用户的浏览器选择和参数偏好。
2. 检查参考图、`assets/models/raw/*.glb`、同名 `.manifest.json`、最终导出目录及游戏资产配置。以实际文件和配置为依据，不只依赖聊天里的“完成”。
3. 按资产类型计数，静态版与绑定版属于同一个资产。风格图、头像、平铺贴图、预览截图不算待建模物体；标准球体、箱体、平面组合通常直接在 Blender 制作。
4. “继续”默认推进清单中下一个未完成的 Tripo 资产，一次完成一类至下载归档。已有在途任务则先接续，不重复提交。用户要求批量时才扩展数量。

本项目的命名、预算见 [references/project-profile.md](references/project-profile.md)；其他项目使用自己的资产清单。

## 上传与生成

- 使用用户指定的网页和浏览器；工具以当前会话可用能力为准，先读其使用文档。不要写死工具版本、标签 ID 或坐标。操作经验见 [references/browser-workflow.md](references/browser-workflow.md)。
- 确认账户已登录并记录生成前积分。用户要求 Chrome 时继续用 Chrome；不要将另一浏览器未登录说成用户没有登录。
- 图中主体应完整、无遮挡、背景可分离。道具通常单图；多视图必须是同一设计、同一比例，按当前正/左/后/右槽位放置。3/4 母图用于单图，不放到“正视”槽。
- 白色主体适合中灰背景；不额外加入细绳、透明玻璃、流苏或地台。确需改图时使用当前可用的图像技能，本技能不自行重画图片。
- 本项目曾使用 `H3.1 – Best Quality`、Ultra Mesh Quality、PBR、Remove Lighting、Quad；AI Complete、Generate in Parts 和 8K 关闭。界面变化时按含义对应，不猜按钮。不更改现有隐私/分享设置。
- 本项目角色最终 2K、道具最终 1K。若生成最低只有 2K，可生成 2K 后在导出选择 1K。
- Polycount 是四边面目标，导出的三角面才用于预算验收。两者通常接近 1:2，但目标面数可能超出，不能拿输入值当结果。
- 读取当前生成价格。任务授权包含本次建模使用已有积分，不自行购买积分、升级套餐或无界重试。费用超出用户预算时停在提交前说明。
- 只点击一次 Generate，记录任务 URL、图片、设置、费用和提交状态。99% 仍可能需要等待，不能重新生成来“刷新”。

## 外形验收与重试

查看正面、侧面、背面及有疑问的顶部/底部，检查轮廓、肢体/轮子/支柱分离、关键特征数量、破洞、背景残片和配色。

- 旋转或预览工具失败时记录未检查角度；文件存在、有贴图、正面好看，都不证明完整环绕验收通过。
- 资源加载失败时先重载同一个结果。`Retry` 可能只重载预览，`Free Retry` 可能立即重新生成，按当前文案辨别。
- 关键特征缺失或结构错误时不标为合格。保存问题截图与原因，优先评估换参考图/模式；在授权及预算内最多先重试一次，仍失败就报告问题及下一步，不连续消耗积分。
- 轻微杂面、尺寸、原点和减面进入 Blender 待办；可归档原始模型，不能称为游戏成品。用户要求最终可用模型时继续完成相应修整与验收。

## 下载与结构校验

1. Export 选择 GLB、明确文件名和贴图尺寸。角色需要绑定时先验证 Rig，另存绑定版而不覆盖静态版；骨骼存在不代表已有动画。
2. 等待下载完成通知并检查实际下载目录。下载监听超时不等于失败，先查文件，避免重复 Export。
3. 复制到项目 `assets/models/raw/` 并保留下载原件。同名文件存在则比较 SHA-256，内容不同另存版本，不能静默覆盖。
4. 用技能提供的脚本检查 GLB 头/分块、缓冲区范围、三角面、内嵌贴图尺寸、骨骼和动画：

   ```bash
   python3 <技能目录>/scripts/inspect_glb.py /绝对路径/cart_tripo.glb --expect-texture 1024 --max-triangles 3000
   python3 <技能目录>/scripts/inspect_glb.py /绝对路径/hero_rigged.glb --expect-texture 2048 --require-rig
   ```

   这只是结构检查，不是完整 glTF 一致性验证器，不证明造型、实际尺寸、渲染或动画变形正确。超预算作为警告保留，不能声称达标。
5. 保存同名 `.manifest.json`：资产名、阶段、来源页面、输入文件、设置、页面面数、实际三角面、贴图尺寸、字节数、SHA-256、积分、骨骼/动画、已完成检查、待办、预览路径。保留旧字段，脚本结果不能覆盖人工外形记录。
6. 保存浏览器中真实模型的预览截图，更新项目进度和下一项。答复链接本地 GLB，说明实际面数/贴图/费用/限制并展示预览，遵守用户语言与称呼要求。

## 完成边界

“图片转 Tripo 原始模型”完成意味着文件已下载归档、结构检查已执行、预览与记录已保存。未做过的环绕检查、Blender 清理、米制缩放、原点、朝向、材质修复、动画、碰撞及游戏加载，一律列在待办中。
