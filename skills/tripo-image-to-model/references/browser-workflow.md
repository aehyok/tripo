# 网页操作经验

按钮和价格随版本变化，以当前界面为准。

## 连接正确页面

绑定用户指定的标签。不要要求用户重复登录已登录的 Chrome，也不要因为另一个浏览器未登录就放弃该标签。

本次会话扩展能枚举 Chrome 标签，但读取/截图曾持续报 `Cannot read properties of undefined (reading 'timeoutMs')`。这是控制通道失败，不代表网站或登录失败。后来用会话提供的 `cua_repl` 原生 Google Chrome 应用接口完成了操作。这是环境经验，不是每次都切换工具的规则：按当前工具/技能限制使用受支持的恢复方式，不绕过安全限制，不读取浏览器私有数据。

原生应用接口可能跟随当前窗口/标签，每次操作前确认标题、URL 和状态。用户换页时不能把生成按钮点击到其他网站；持续争用控制则暂停说明。

## 输入与设置

- `3D Workspace` 链接可返回新生成面板，旧参考图可能保留，先清除再上传。清除输入图不等于删除已生成资产。
- 单图、多视图、批量、文字使用不同入口，看当前图标/标签，不复用历史索引。
- 原生文件选择器用“前往文件夹”填绝对路径，先确认输入框已出现再输入和确认。过早连发快捷键/文字曾导致路径丢字。
- Geometry & Texture 沿用上一次设置，每个新资产都要核对。Polycount 输入后失焦再关闭，使其保存。
- 本次界面生成最低 2K，但导出可选 1K。不要混淆生成档位与导出尺寸。

## 等待与验收

- 提交后记录新任务 URL，Generate 重新可点也不要再点。
- 99% 会停留一段时间，完成后还需等模型和贴图加载。
- “Failed to load resource” 曾在完成后出现，点击错误下的 Retry 重载同一个模型，没有新生成费用。
- PBR 曾暂时黑屏，可先看灰模再等贴图；不能据此认定 GLB 无贴图。分别记录“文件有贴图”与“实际渲染通过”。
- 原生拖动曾没有旋转效果，因此摊位、小吃车、皮纳塔侧后方仍待验收。调用 drag 成功不证明角度已检查。
- 画布缩放敏感，少量调整后观察；不要复制其他分辨率的坐标。

## 导出

Export 填不带扩展名的资产名，选择 GLB 和目标贴图尺寸。下载完成通知和真实文件是依据，事件超时也可能已落盘。

使用 `*_tripo.glb` 标原始版、`*_rigged_tripo.glb` 标绑定版，保留静态版。网站自动名称不可靠，例如七角星被命名 five-point-star，特征数量以实际模型为准。

关掉导出面板与下载浮层后保存预览，保留必要上下文，不为截图重新生成。
