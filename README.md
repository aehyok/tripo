# 环球寻物

一个以 3D 地球为入口的单人寻物小游戏。玩家操控寻物员“小年”，进入墨西哥球迷街，寻找穿绿色球衣的小狗“吉拿”。

项目已按 PRD v0.4 迁移到 **CesiumJS**：地球与第一关街区都由 Cesium 渲染，界面为网页覆盖层。
当前使用程序生成的占位模型，正式 Tripo 资产尚未接入（见[资产生产手册](./资产生产手册.md)）。

## 快速开始

需要 Node.js 18+。

```bash
npm install
npm run dev        # 开发环境 http://127.0.0.1:5173/
npm run build      # 生产构建，输出到 dist/
npm run preview    # 本地预览构建产物 http://127.0.0.1:4173/
```

首次加载需要网络：Cesium 静态资源随项目部署（`node_modules/cesium` → `dist/cesium`），
字体使用 Google Fonts（不可用时回退系统字体）。地球底图为运行时自绘的风格化贴图，
**不依赖任何在线地图或影像服务**，断网也能进入第一关。

## 操作

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | W/A/S/D 或方向键 | 左下虚拟摇杆 |
| 转视角 | 按住鼠标拖动 | 在场景空白处拖动 |
| 缩放 | 鼠标滚轮 | 双指缩放 |
| 蹲下／站起 | C 键切换 | 右侧“蹲”按钮切换 |
| 确认找到吉拿 | E 键或“抱起吉拿”按钮 | “抱起吉拿”按钮 |
| 提示 | “听叫声”按钮（每局 2 次） | 同左 |

## 实现要点

- **坐标系**：街区锚点 `-99.1332, 19.4326, 2240m`，所有物件、藏点、碰撞与距离都用局部 ENU 米制坐标，
  不用经纬度差计算距离（PRD 10.2）。
- **地球**：运行时用 Canvas 绘制风格化世界地图作为单张底图，墨西哥用地面多边形高亮，
  小点只表示大致区域。点击判定带触屏容错范围。
- **街区**：占位模型由 Cesium 实体（box / cylinder / ellipsoid / polyline）拼装，
  正式 GLB 只需在 `src/config.js` 填路径即可替换；GLB 缺失或载入失败时自动回退占位模型。
- **碰撞与视线**：房屋、摊位、小吃车维护轴对齐包围盒；移动做滑动碰撞，
  确认吉拿需要“距离 < 2.2 米且视线无遮挡”同时成立（PRD 7.2）。
- **相机**：第三人称跟随，被建筑挡住时先尝试转向，再抬高视角并拉近距离；
  靠近吉拿时相机绕到侧面，避免小狗被角色挡住。
- **状态**：单一 `mode` 状态机 + 回合令牌，离场会取消镜头飞行、延迟结算与庆祝特效，
  快速连点不会重复启动流程（PRD 9.1 / 12.2）。

## 与 PRD 的对应

已按 PRD 第 11 节差距清单处理：

| 项 | 处理 |
| --- | --- |
| P0 Cesium 迁移 | 地球、街区、角色、寻物、结算、返回全部由 Cesium 渲染 |
| P0 房后藏点不可达 | 重新排布街区，三个藏点均有 1.5 米以上通路，已用网格搜索验证可达 |
| P0 通关后延迟结算弹到地球 | 离场清除结算定时器与彩纸，回合令牌使旧回调失效 |
| P0 进场动画影响选关页 | 返回时取消镜头飞行，并恢复地球浏览控制 |
| P0 超时遮罩不消失 | 15 秒提示“加载较慢”，资源就绪后遮罩必定移除 |
| P0 确认只判距离 | 增加角色到吉拿的视线检测，隔墙不出现“抱起吉拿” |
| P1 足球提示与藏点矛盾 | 改为中性文案 |
| P1 后五关状态不统一 | 后五关统一“制作中”，点击提示“当前版本仅开放第一关” |
| P1 正式资产未接入 | 预留 `ASSETS` 配置与 GLB 加载、失败回退 |
| P1 无下蹲 | C 键／手机按钮切换，相机降 0.7 米、速度 60%、蹲姿姿态，结算与失焦自动站起 |

尚未完成（依赖正式资产或外部确认）：吉拿与小年的正式模型与动画、目标卡片正式出图、
卢佩与莫馆长头像、地图合规与上线范围、验收设备上的帧率实测。
