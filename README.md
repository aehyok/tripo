# 环球寻物

一个以 3D 地球为入口的单人寻物小游戏。玩家操控寻物员“小年”，进入墨西哥球迷街，寻找穿绿色球衣的小狗“吉拿”。

当前处于第一关原型阶段，使用 Three.js 和程序生成的占位模型，正式 Tripo 资产尚未接入。首页保留六个关卡入口，本期仅制作第一关。

## 本地运行

安装 Python 3 后，在项目目录运行：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 [本地目录](http://127.0.0.1:8000/)，点击 `环球寻物.html`。

页面需要支持 WebGL 和 ES Modules 的浏览器。Three.js 通过 jsDelivr 加载，字体使用 Google Fonts，首次加载需要网络连接。后续接入本地 GLB 模型时也通过 HTTP 服务访问。

## 操作

- 选择第一关，在地球上点击墨西哥区域或小点进入街区。
- 电脑：WASD 或方向键移动，按住鼠标拖动转视角，滚轮缩放。
- 手机：左下摇杆移动，拖动场景转视角，双指缩放。
- 靠近吉拿后按 E 或点击“抱起吉拿”完成任务。
- 每局可使用两次提示；用时和提示次数影响星级。
